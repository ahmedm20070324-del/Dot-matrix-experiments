# Dot Matrix Experiments 🚀

A collection of hardware experiments, code examples, and circuit setups for working with dot matrix LED displays—ranging from basic 8x8 LED matrix testing to MAX7219-driven scrolling text displays.

---

## 📌 Overview

This repository documents my experiments and projects working with dot matrix displays:
- **Basic 8x8 LED Matrix**: Understanding multiplexing, row/column scanning, and direct pin control.
- **MAX7219 Driver Integration**: Controlling single and daisy-chained 8x8 LED matrix modules efficiently over SPI/digital pins.
- **Scrolling Text & Marquee**: Generating smooth text scrolling, custom characters, and animations.
